# 关于可控死亡惩罚的文档

## 简介

可控死亡惩罚将玩家死亡时“全部掉落”或“全部保留”的固定规则替换为逐格独立的随机检查。模组完全由服务端决定，并将一套全局规则保存到世界存档中；使用指令修改后立刻生效，重启服务器后仍会保留。

原版 `keepInventory` 游戏规则始终优先。它开启时，本模组不会掉落物品、扣除经验或损坏装备。

## 兼容的模组
- Traveler's Backpack (旅行者背包)

## 完整规则结构

```text
{
    DropChance: <浮点>,
    MinDropPerc: <浮点>,
    MaxDropPerc: <浮点>,
    MinExperienceLossPerc: <浮点>,
    MaxExperienceLossPerc: <浮点>,
    DoArmorDrop: <布尔>,
    DoMainhandDrop: <布尔>,
    DoOffhandDrop: <布尔>,
    DoToolbarDrop: <布尔>,
    StackInsurance: <布尔>,
    NonStackableInsurance: <布尔>,
    DoDurabilityLoss: <布尔>,
    DurabilityLossChance: <浮点>,
    MinDurabilityLossPerc: <浮点>,
    MaxDurabilityLossPerc: <浮点>,
    DurabilityInsurance: <布尔>,
    MaxExperienceOrbs: <整数>,
    WhiteList: [<物品命名空间标识符>, ...]
}
```

所有百分比均接受 `0.0` 至 `1.0` 的值；每个最小值不得大于其对应最大值。

## 死亡处理机制

每个非空物品格都会独立处理。白名单物品会在任何随机检查前被跳过，因此永不掉落、永不承受耐久损失。

当前选中的快捷栏格为主手格；其余八个快捷栏格为工具栏格。主背包的 27 格始终使用普通掉落规则；护甲、当前主手、副手和其余工具栏格分别由对应布尔参数控制。

安装 Traveler's Backpack 11.3.2 且未启用其 Trinkets 外部装备集成时，模组也会拦截 Traveler's Backpack 的原生已装备背包槽。已装备的背包作为一个独立、允许掉落的不可堆叠物品格使用普通规则，因此默认会被 `NonStackableInsurance` 保留；关闭该保险后，`DropChance` 才能决定是否触发其原生死亡掉落。也可将具体背包物品 ID 加入 `WhiteList` 使其始终保留。检查成功后会交由 Traveler's Backpack 自身处理，因此会遵循该模组的死亡地点自动放置、虚空保护及无法放置时掉出物品等设置。CDP 只处理背包物品本身，不会遍历或独立检查背包内部库存；内部物品会作为背包组件数据的一部分原样随背包保留、放置或掉落。Trinkets、饰品模组或其他模组提供的外部槽位不在本项兼容范围内。

对于具有耐久的不可堆叠物品，模组首先执行耐久检查：

1. 必须启用 `DoDurabilityLoss`。
2. 独立的 `DurabilityLossChance` 检查必须成功。
3. 在 `MinDurabilityLossPerc` 至 `MaxDurabilityLossPerc` 间均匀随机选择比例，乘以物品的满耐久度并向上取整。
4. 开启 `DurabilityInsurance` 时至少保留 1 点耐久；关闭时，耐久损失可能在掉落检查前摧毁物品，此时已经没有物品可以掉落。

如果物品仍然存在，随后执行相互独立的 `DropChance` 检查：

1. 允许掉落格中的不可堆叠物品在检查成功且关闭 `NonStackableInsurance` 时整件掉落；开启该保险时物品留在原格。
2. 允许掉落格中的可堆叠物品会在 `MinDropPerc` 至 `MaxDropPerc` 间均匀随机选择比例，计算掉落数后向上取整并从原堆叠扣除。
3. 开启 `StackInsurance` 后，任意堆叠不会掉落最后一个物品；只有一个物品的堆叠即使检查成功也会保留。
4. 关闭掉落的格子无论 `DropChance` 结果如何都不会掉落物品，但其独立耐久检查仍然生效。

由于两个检查相互独立，允许掉落格中的耐久物品可以出现“损伤且掉落”“不损伤且不掉落”“不损伤但掉落”“损伤但不掉落”四种结果。每个物品格分别使用独立随机检查。

## 经验处理机制

模组读取玩家死亡时的当前总经验，在 `MinExperienceLossPerc` 至 `MaxExperienceLossPerc` 间均匀随机损失比例并向上取整，然后从玩家扣除等量经验。

死亡位置会生成总值完全相同的经验球。`MaxExperienceOrbs` 通过将总经验尽量均分到至多该数量的经验球中来限制实体数量；它只改变经验球的数量和值，不改变总经验，因此扣除的每一点经验都能以经验球形式拾取。

## 参数说明

```text
DropChance
含义：单个物品格检查成功的概率
类型：浮点
范围：[0.0, 1.0]
默认：0.5

MinDropPerc / MaxDropPerc
含义：可堆叠物品掉落比例的均匀随机范围
类型：浮点
范围：[0.0, 1.0]，且 MinDropPerc <= MaxDropPerc
默认：0.1 / 0.5
备注：计算出的掉落数量会向上取整

MinExperienceLossPerc / MaxExperienceLossPerc
含义：死亡时按当前总经验损失的均匀随机比例范围
类型：浮点
范围：[0.0, 1.0]，且 MinExperienceLossPerc <= MaxExperienceLossPerc
默认：0.1 / 0.5

DoArmorDrop
含义：四个护甲格是否允许掉落
类型：布尔
默认：false

DoMainhandDrop
含义：当前选中的快捷栏格是否允许掉落
类型：布尔
默认：false

DoOffhandDrop
含义：副手格是否允许掉落
类型：布尔
默认：false

DoToolbarDrop
含义：其余八个未选中快捷栏格是否允许掉落
类型：布尔
默认：true

StackInsurance
含义：阻止任意会被完全掉空的堆叠掉落最后一个物品
类型：布尔
默认：true

NonStackableInsurance
含义：阻止不可堆叠物品因掉落检查成功而被整件移出；每个物品格独立保护
类型：布尔
默认：true
备注：只阻止掉落，不阻止独立耐久损失；关闭 DurabilityInsurance 时物品仍可能因耐久耗尽而被摧毁

DoDurabilityLoss
含义：是否为具有耐久的不可堆叠物品启用独立耐久损失检查
类型：布尔
默认：true

DurabilityLossChance
含义：符合条件的物品受到耐久损失的概率；此项先于且独立于 DropChance 检查
类型：浮点
范围：[0.0, 1.0]
默认：0.5

MinDurabilityLossPerc / MaxDurabilityLossPerc
含义：以物品满耐久度为基准的耐久损失均匀随机比例范围
类型：浮点
范围：[0.0, 1.0]，且 MinDurabilityLossPerc <= MaxDurabilityLossPerc
默认：0.05 / 0.2
备注：计算出的耐久损失会向上取整

DurabilityInsurance
含义：阻止耐久补偿惩罚真正摧毁物品
类型：布尔
默认：true

MaxExperienceOrbs
含义：一次玩家死亡最多生成的经验球实体数量
类型：整数
范围：[1, 2147483647]
默认：10

WhiteList
含义：免除掉落和耐久损失的物品命名空间标识符列表
类型：标识符列表
默认：空
示例：minecraft:totem_of_undying、othermod:valuable_item
备注：`whitelist add` 会根据当前服务器实际注册的物品提供自动补全，并拒绝不存在或未加载的物品 ID。`whitelist remove` 会自动补全当前白名单中的条目，同时仍允许输入任意合法标识符，以便在卸载某个模组后清理其遗留白名单项
```

## 指令

`/cdp get` 对所有命令来源开放。其余会修改规则的指令要求权限等级 4。

```text
/cdp get
/cdp help
/cdp reset

/cdp set dropChance 0.5
/cdp set minDropPerc 0.25
/cdp set maxDropPerc 0.75
/cdp set minExperienceLossPerc 0.1
/cdp set maxExperienceLossPerc 0.5
/cdp set doArmorDrop true
/cdp set doMainhandDrop true
/cdp set doOffhandDrop true
/cdp set doToolbarDrop false
/cdp set stackInsurance true
/cdp set nonStackableInsurance true
/cdp set doDurabilityLoss true
/cdp set durabilityLossChance 0.5
/cdp set minDurabilityLossPerc 0.05
/cdp set maxDurabilityLossPerc 0.2
/cdp set durabilityInsurance true
/cdp set maxExperienceOrbs 10

/cdp whitelist add minecraft:totem_of_undying
/cdp whitelist remove minecraft:totem_of_undying
/cdp whitelist list
```

如果某次百分比设置会让最小值大于对应最大值，指令会拒绝该修改。`/cdp reset` 会恢复全部默认值并清空白名单。

`/cdp help` 提供精简的游戏内帮助：`/cdp help command` 列出全部可用指令，`/cdp help parameter <参数>` 显示一个具体参数的范围、可选值和作用。完整说明仍以本文件为准。

`/cdp whitelist add` 的物品参数与服务器物品注册表关联。输入时可以使用 Tab 检索已加载的原版及模组物品；拼错或不存在的 ID 会直接报告未知物品。`/cdp whitelist remove` 的 Tab 候选来自当前白名单本身，包括所属模组已经卸载的遗留项；移除操作不要求物品仍然存在，也可以继续手动输入完整 ID。
