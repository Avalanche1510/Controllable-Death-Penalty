# 关于可控死亡惩罚的更新日志

## 简介

用于记录可控死亡惩罚的 Git 内容更新，并尽可能完整、细致地记录行为与文档变化。

# 格式

年.月.日-序数

## 记录

### 26.7.26-1

将经验损失比例上限的默认值从 25% 调整为 50%。已有世界会保留已保存的数值；使用 `/cdp set maxExperienceLossPerc 0.5` 或 `/cdp reset` 即可应用新默认值。

修复 `/cdp whitelist add` 与 `/cdp whitelist remove` 无法接受带冒号的完整物品命名空间标识符。两个指令现在使用 Minecraft 的标识符参数类型，可直接接受 `minecraft:diamond`、`othermod:test_item` 等值。

加入 GameTest 断言，验证 50% 默认值以及带命名空间的白名单指令解析。

### 26.7.25-4

加入默认值为 50% 的 `DurabilityLossChance`。耐久损失不再由 `DropChance` 的成功或失败决定。

每个符合条件、具有耐久的不可堆叠物品现在会先执行独立的耐久损失检查，再执行独立的掉落检查。因此，允许掉落的物品可以出现“损伤且掉落”“不损伤且不掉落”“不损伤但掉落”“损伤但不掉落”四种结果。关闭槽位掉落只会拦截掉落结果，不会拦截独立的耐久检查。

加入向后兼容的世界数据解码：在该参数出现前创建的世界会将 `DurabilityLossChance` 读取为 0.5，同时保留其他已有规则，不会重置配置。

加入 `/cdp set durabilityLossChance <0.0-1.0>`，并在 `/cdp get` 与 `/cdp reset` 中纳入新参数。

扩展服务端 GameTest，以确定性方式验证四种耐久/掉落组合以及保留或掉出物品的实际耐久值。

### 26.7.25-3

修复 Minecraft 26.1.1 中护甲与副手的掉落保护。在这一版本中，`Inventory.getContainerSize()` 除了 36 个普通背包格，还包含 7 个映射装备格。此前的普通背包循环因此会把护甲和副手当作允许掉落的普通背包格再次处理，从而绕过 `DoArmorDrop` 与 `DoOffhandDrop`。

普通背包的死亡处理、快照与恢复现在只遍历 `Inventory.getNonEquipmentItems()`。护甲和副手仅通过各自的专用规则处理一次。

加入覆盖完整死亡与复活流程的确定性服务端 GameTest。在掉落概率为 100%、关闭护甲与副手掉落且关闭耐久损失时，测试会分别验证死亡结算后和新玩家实体复活后物品及耐久值严格不变，并使用允许掉落的主手物品作为对照组。

### 26.7.25-2

修复死亡检查后保留下来的物品在复活时仍然消失的问题。现在会将死亡玩家在自定义检查后保留的物品与经验复制到新生成的复活玩家实体。

将可堆叠物品的默认掉落范围从固定 50% 改为均匀随机 10%–50%（`MinDropPerc = 0.1`、`MaxDropPerc = 0.5`）。已有世界会保留已保存的数值；使用 `/cdp set minDropPerc 0.1`、`/cdp set maxDropPerc 0.5` 或 `/cdp reset` 即可应用新默认值。

修正经验损失计算：现在从原版等级曲线与当前经验条进度计算实际持有经验，并在复活后同步准确的剩余经验。

将经验条进度还原为经验点时由向下截断改为有边界的四舍五入，避免浮点表示误差使多次死亡额外损失 1 点经验。

在旧玩家实体被移除前快照护甲和副手装备，以便即使原版清空实体装备后也能恢复受保护的物品。耐久补偿现在也会作用于允许掉落但概率检查失败、因此未掉落的工具；实际掉出的物品绝不会受损。

### 26.7.25-1

首个版本，适用于 Minecraft 26.1.1、Fabric Loader 0.19.3 与 Fabric API 0.145.4。

加入服务端决定、按世界全局保存的死亡惩罚配置。规则写入世界存档，服务器重启后仍会保留，使用指令修改后立即生效。

加入对玩家每个非空物品格的独立死亡检查。护甲、当前选中主手、副手和其余八个快捷栏格拥有独立掉落开关；普通主背包 27 格始终使用普通掉落规则。

加入 `DropChance` 与 `MinDropPerc` / `MaxDropPerc`。可堆叠物品在范围内均匀随机选择掉落比例，并将掉落数量向上取整；不可堆叠物品在格子检查成功时整件掉落。

加入 `StackInsurance`，阻止任意堆叠掉落最后一个物品。

加入掉落开关关闭时的补偿性耐久损失。成功的 `DropChance` 检查可以让具有耐久的不可堆叠物品按其满耐久度的均匀随机比例受损。加入 `DoDurabilityLoss`、`MinDurabilityLossPerc`、`MaxDurabilityLossPerc` 与 `DurabilityInsurance`；开启保险时物品至少保留 1 点耐久。

加入物品命名空间白名单。白名单中的原版和模组物品会跳过全部死亡掉落与耐久检查。

加入基于当前总经验的随机经验损失，由 `MinExperienceLossPerc` 与 `MaxExperienceLossPerc` 控制。扣除的经验会在死亡位置以经验球形式掉出，经验总值严格守恒。

加入默认值为 10 的 `MaxExperienceOrbs`。它会将准确损失的经验尽量均分到最多该数量的经验球中，以限制生成的实体数量。

加入所有人可查询的 `/cdp get`。加入要求权限等级 4 的参数设置、恢复默认、白名单添加、移除与列出指令。

原版 `keepInventory` 游戏规则优先；它开启时，本模组不会掉落物品、扣除经验或损坏装备。

加入完整的中英文 README、模组文档与更新日志。
